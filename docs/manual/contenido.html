Cómo utilizar este manual. Ábrelo con doble clic en el navegador. Funciona sin conexión y contiene sus imágenes integradas. Utiliza el índice, el buscador o el botón de imprimir. Las rutas se cuentan desde la carpeta principal del proyecto.

Qué incluye el software

Una página de presentación, catálogo de productos, soluciones, proyectos, formulario de afiliados y enlaces de contacto por WhatsApp. Está construida con React y Vite. El contenido se edita en archivos locales y las imágenes están dentro de src/assets.

El sitio no tiene un panel de administración conectado a una base de datos. Guardar un archivo actualiza la vista local mientras está abierto el servidor de desarrollo; para modificar la web publicada se debe compilar y publicar de nuevo.

01 / PREPARACIÓN

Abrir la página en tu computadora

  1. Conserva una copia del proyecto. Antes de una actualización, guarda un respaldo o registra el estado con Git. Incluye las carpetas de contenido e imágenes.
  2. Prepara las herramientas. Necesitas Node.js con npm y un editor de código. Usa una versión de Node compatible con las dependencias entregadas; los scripts originales de recuperación requieren Node 20 o superior.
  3. Abre la carpeta principal en el editor. Debes ver package.json, src, public y docs. Abre ahí la terminal.
  4. Instala las dependencias. Solo es necesario la primera vez o cuando cambian las dependencias. Requiere acceso a internet si no están disponibles localmente.
npm ci

Inicia la vista de trabajo:

npm run dev

La terminal mostrará una dirección local. Abre exactamente esa dirección en el navegador. Mantén la terminal abierta mientras editas. Ctrl + C detiene el servidor.

Editar contenido→Guardar→Revisar en navegador→Validar y publicar
No abras el index.html de la aplicación con doble clic para probar React. La página necesita el servidor de Vite durante el desarrollo. Este manual sí puede abrirse directamente como archivo HTML.

03 / TEXTOS

Cambiar una frase sin tocar el diseño

  1. Identifica la sección. Por ejemplo, el título de soluciones se encuentra en src/contenido/servicios/textos/SolucionesCarrusel.json.
  2. Busca la frase que ves en la página.
  3. Edita solo el valor situado a la derecha de los dos puntos.
  4. Guarda y revisa el navegador. Conserva el nombre de la clave.

Antes

"disenamos_espacios_funcionales_y_modernos":
  "Diseñamos espacios funcionales y modernos"

Después

"disenamos_espacios_funcionales_y_modernos":
  "Creamos espacios a tu medida"
El ejemplo muestra una entrada del objeto JSON. Conserva las llaves del archivo y las comas entre entradas. No agregues una coma después de la última entrada.

Reglas que evitan errores

  • JSON utiliza comillas dobles, no admite comentarios y no permite comas sobrantes.
  • Para un salto de línea dentro del valor escribe \n. Para incluir comillas dobles escribe \".
  • Los nombres de archivo de textos/ indican el componente que los utiliza: Portada.json, Nosotros.json, Valores.json, etc.
  • Los títulos y descripciones de productos se editan en sus categorías; los nombres y descripciones de proyectos en su lista única.

Plantillas automáticas

Las claves que comienzan con plantilla_ pueden contener {dato1}, {dato2}, etc. La página los sustituye por un nombre de producto, acabado o dato del formulario. Conserva esos marcadores aunque cambies el resto de la frase.

"plantilla_resultado_de_referencia_dato1":
  "Resultado simulado: {dato1}"

Para cambiar el título principal de portada utiliza PORTADA.titulo y PORTADA.descripcion en src/contenido/general/sitio.js.

05 / FOTOGRAFÍAS

Una imagen, una ubicación clara

La opción más sencilla: reemplazar el mismo archivo

  1. Busca el producto o la sección en src/contenido.
  2. Localiza la ruta de su imagen en el import al principio del archivo. También puedes usar el inventario incluido al final del manual.
  3. Prepara la nueva fotografía con el mismo nombre, extensión y carpeta.
  4. Reemplaza el archivo, guarda y revisa la página.

Si cambias el nombre, modifica también la importación:

import fotoMiPuerta from
  '../../../assets/catalogo/puertas/mi-puerta.webp'
Cambiar .jpg por .webp en el nombre no convierte una fotografía. Exporta o convierte el archivo con una herramienta de imágenes antes de sustituirlo.
CarpetaQué contiene
src/assets/marcaLogotipo.
src/assets/inicioPortadas, empresa y miniaturas de especialidades en servicios/.
src/assets/catalogoProductos por categoría y sus variantes.
src/assets/proyectosUna carpeta por proyecto, con imágenes de antes y después.
src/assets/documentacionMaterial conservado de referencia, sin selección automática para publicar.

Para nuevas imágenes utiliza nombres claros, preferentemente sin espacios ni acentos. Como orientación, una tarjeta suele necesitar de 640 a 1000 píxeles de ancho; una portada requiere más resolución. WebP ayuda a reducir el peso. Conserva la proporción y revisa el recorte en móvil.

Tres registros, tres propósitos

  • imagenes/INVENTARIO.md: ubicación, peso y archivos que utilizan cada imagen.
  • imagenes/origenes.json: fuentes originales para recuperación de archivos registrados.
  • imagenes/generadas.json: prompts y ubicaciones de las imágenes generadas con IA. No selecciona por sí mismo lo que aparece en la página.

Ejemplo: agregar una puerta

  1. Coloca la fotografía en src/assets/catalogo/puertas/mi-puerta.webp.
  2. Abre src/contenido/catalogo/categorias/puertas.js y añade el import al principio.
  3. Agrega un objeto dentro de productos, con un ID nuevo y único.
  4. Guarda y ejecuta la validación.
import fotoMiPuerta from '../../../assets/catalogo/puertas/mi-puerta.webp'

// Dentro de la lista productos, separado por una coma:
{
  id: 'p-mi-puerta',
  TITULO: 'Puerta a medida',
  slug: 'mi-puerta',
  img: fotoMiPuerta,
},

El orden dentro de productos es el orden de presentación. El orden de las categorías se configura en src/contenido/catalogo/productos.js. Para una categoría nueva, crea su archivo, impórtalo allí y revisa sus recomendaciones en servicios/categorias-relacionadas.js.

Antes de eliminar un producto, revisa si su ID aparece en el carrusel. Cambia esas referencias para no dejar imágenes o enlaces inexistentes.

10 / PROYECTOS

Una sola ficha para todos los lugares

Todos los proyectos se editan en src/contenido/proyectos/lista.js. Una misma ficha puede aparecer en el collage del inicio, en la página de proyectos o en ambos lugares.

Este es el estilo fijo del collage en PC

Esquema documental con las mismas imágenes del sitio. El diseño está declarado en src/pages/inicio/componentes/proyectosCollage.css. Conserva una imagen grande a la izquierda y dos a la derecha; en celular mantiene la distribución vertical.

Cambiar un destacado sin romper el collage. Debe existir exactamente un proyecto en cada posición 1, 2 y 3. Pon false en el proyecto anterior y asigna ese número al nuevo. El orden de la lista no modifica estas posiciones.

Agregar un proyecto paso a paso

  1. Crea src/assets/proyectos/casa-lopez.
  2. Coloca ahí sus fotografías, por ejemplo antes.webp y despues.webp.
  3. Importa ambas imágenes al principio de lista.js.
  4. Copia un bloque de proyecto y completa sus datos.
import casaAntes from '../../assets/proyectos/casa-lopez/antes.webp'
import casaDespues from '../../assets/proyectos/casa-lopez/despues.webp'

// Dentro de PROYECTOS:
{
  id: 'casa-lopez',
  nombre: 'Casa López',
  tipo: 'Residencial',
  descripcion: 'Renovación de ventanas de aluminio.',
  detalle: 'Ventanas · Aluminio',
  portada: casaDespues,
  antes: casaAntes,
  despues: casaDespues,
  destacado: false,
  mostrarEnRecientes: true,
  ejemplo: false,
},

Utiliza ejemplo: false solo cuando los datos y fotografías correspondan al trabajo real que estás publicando. Para una simulación, conserva true. Si no hay foto de antes, escribe antes: null; el bloque de antes se oculta. Un proyecto reciente requiere foto de después.

seleccion.js prepara automáticamente las listas. No dupliques las fichas allí ni en los archivos de inicio. fotografias.js comparte imágenes con otras secciones, pero no almacena fichas de proyectos.

Cómo funciona el formulario de afiliados

El visitante escribe los datos, revisa el resumen y continúa en WhatsApp. La información no se registra automáticamente en un servidor. La opción de recordar datos guarda únicamente los datos de quien refiere en el almacenamiento local de su navegador.

El monto o porcentaje de una recompensa no está definido automáticamente por el sitio. Actualiza las condiciones del programa de acuerdo con lo que la empresa haya establecido y conserva los marcadores de la plantilla de WhatsApp.
