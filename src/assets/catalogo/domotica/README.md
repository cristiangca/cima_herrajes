# Imágenes de domótica

Cada producto tiene su propia imagen ilustrativa generada con IA y guardada localmente en WebP:

| Archivo | Producto |
| --- | --- |
| persianas-simulado.webp | Domótica para persianas |
| puertas-simulado.webp | Domótica para puertas |
| iluminacion-simulado.webp | Iluminación inteligente |
| cerraduras-simulado.webp | Cerraduras inteligentes |
| vidrio-simulado.webp | Control para vidrio inteligente |
| motores-simulado.webp | Motores automatizados |
| sensores-simulado.webp | Sensores y control inteligente |

Las referencias se editan en src/contenido/catalogo/categorias/domotica.js. El carrusel usa estos mismos productos y abre el producto mostrado al pulsar su imagen.

Son ilustraciones de aplicación, no fotografías certificadas de un modelo o marca comercial. Los archivos PNG anteriores se conservan, pero el catálogo utiliza las nuevas imágenes WebP.

Los prompts y el registro de generación están en src/contenido/imagenes/generadas.json. Para sustituir una foto conserva su nombre o cambia la importación de la categoría.
