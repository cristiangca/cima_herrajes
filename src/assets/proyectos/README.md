# Fotografías de proyectos

Los tres proyectos actuales son simulados. Cada uno tiene sus propias imágenes de antes y después, generadas a partir del mismo espacio:

- luz-y-amplitud/antes-simulado.webp y despues-simulado.webp: renovación de una puerta corrediza residencial.
- transparencia/antes-simulado.webp y despues-simulado.webp: sustitución de barandal de hierro por cristal templado.
- nueva-mirada/antes-simulado.webp y despues-simulado.webp: renovación de una fachada comercial.

Sus datos se editan solamente en src/contenido/proyectos/lista.js. ejemplo: true mantiene la identificación de proyecto simulado. El collage conserva una imagen grande a la izquierda (fachada) y dos a la derecha (residencial arriba y barandales abajo).

Las imágenes originales de referencia y las antiguas carpetas gravase, plaza-norte y oficinas-vertex se conservan como material anterior. Los proyectos visibles utilizan los archivos -simulado.webp.

Para reemplazar una simulación por un trabajo real, actualiza las imágenes de su carpeta y los datos de lista.js. El registro de prompts está en src/contenido/imagenes/generadas.json.
