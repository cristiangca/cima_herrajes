# Afiliados

- `servicios.js`: opciones del formulario, en el orden en que aparecen.
- `textos/Afiliados.json`: presentación, pasos, etiquetas, condiciones, mensajes y plantilla de WhatsApp.

La plantilla de WhatsApp utiliza `{dato1}`, `{dato2}`, etc. para insertar los valores del formulario; conserva esos marcadores. La validación y la función de recordar datos siguen en `src/pages/Afiliados.jsx`.
